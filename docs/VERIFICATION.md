## Принятые решения реализации

- Отдельная таблица протокола не добавлена сверх восьми сущностей, перечисленных в ЛР №5. Для соответствия архитектуре ЛР №5/6 Compose использует PostgreSQL 15. В учебном MVP протокол представлен финализированным `PortfolioScenario` и связанными `CommitteeVote`; дата берётся из `finalized_at`, экспортный идентификатор имеет вид `PPM-{scenario_id}`.
- LDAP и SMTP проверяются только в Compose-режиме. При локальном режиме на Arch используется пароль, сохранённый в БД Django, а почтовые события направляются на указанный SMTP-хост.
- В текущей среде подготовки отсутствовали Docker и доступ к реестрам пакетов, поэтому `docker compose up --build`, сборка React с загрузкой npm-зависимостей и сквозные проверки PostgreSQL/OpenLDAP/Mailpit здесь не выполнялись.
